Guide d'utilisation

Processus en 4 étapes:
  1. Dépôt source: Sélectionnez d'où vient le stock
  2. Produit: Choisissez le produit à transférer (Seuls les produits en stock s'affichent)
  3. Dépôt destination: Vers quel dépôt transférer
  4. Quantité: Combien d'unités transférer
Types de transferts:
  • Magasin → Magasin
  • Magasin → Point de vente
  • Point de vente → Magasin
  • Point de vente → Point de vente
Règles importantes:
  • Source ≠ Destination
  • Quantité ≤ Stock disponible
  • Historique complet conservé
  • Stocks mis à jour automatiquement
